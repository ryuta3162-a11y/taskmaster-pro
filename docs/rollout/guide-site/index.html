ログイン・登録

To Do List とは何ですか？

TFチームや本部からの依頼（To Do）を一か所で受け取り、対応したら完了を報告するためのアプリです。

  • 自分宛ての依頼はリストチェックにまとまります。
  • 依頼を出した人は、誰が完了したかを確認でき、未完了の人だけに催促できます。
  • 期限が近づくと、未完了の人に自動でリマインドメールが届きます。
ログインのしかたを教えてください
  1. このページ右上の To Do List を開く を押します（To Do List のホーム画面の「マニュアルはこちら」からもこのページに来られます）。
  2. ログイン画面にご自身の社内メールアドレスを入力し、ログイン / 新規登録 を押します。
  3. はじめての方は、続けてプロフィール登録の画面になります。登録済みの方は内容を確認して このアカウントで開始 を押します。

一度ログインすると、次からは同じ端末・ブラウザでそのまま開けます。

初回登録では何を入力しますか？
お名前氏名を入力します。依頼や完了記録に表示されます。
あなたの役職GMG・A-SMG・SMG・TMG・CMG・CL・CF・IR から選びます。社員への依頼はこの役職で届きます。
チーム名所属するTFチームを選びます（複数選択可・必須）。TFチームの依頼はこのチームで届きます。
エリア担当するエリアを選びます（複数選択可）。
テリトリー選んだエリアのテリトリーが表示されます。担当しないテリトリーだけタップして外します。
管轄店舗選んだテリトリーの店舗が表示されます。管轄外の店舗だけタップして外します（最大50店舗）。店舗への依頼はここで選んだ店舗について届きます。

入力したら 登録して開始 を押します。

本部所属の方（第1〜第7エリアに所属しない方）は、エリアの代わりに 本部所属 を選びます。エリア・店舗の選択は不要です。社員への依頼・TFチームの依頼は届きますが、店舗への依頼は届きません。

店舗のメールアドレスでログインできますか？

できません。店舗の共用メールではログイン・登録ができないようになっています。

共用メールでの利用は、誰が完了したのか分からなくなるほか、アルバイトスタッフへの情報漏洩につながるためです。必ずご自身の社内メールをお使いください。

店舗のスタッフに依頼内容を伝えたいときは、店舗アドレスへ共有を使ってください。

「ファイルを開くことができません」などと表示されて開けません

ブラウザで複数の Google アカウントに同時にログインしていると起きることがあります。次のどれかをお試しください。

  1. ブラウザのシークレットウィンドウ（Chrome は Ctrl＋Shift＋N）を開き、社内アカウントだけでログインしてから To Do List を開く。
  2. Google の右上のアイコンから、一度すべてのアカウントからログアウトし、社内アカウントを最初にログインし直す。
  3. 個人の Google アカウントでは開けません。社内アカウント（@okamoto-group.co.jp）でログインしているか確認する。

それでも開けない場合は、表示された画面を撮影してDXチームまでご連絡ください。

開くまでに時間がかかります

開いた直後は「システムを起動しています...」と表示され、数秒〜十数秒かかることがあります。画面を閉じずにそのままお待ちください。

  • 30秒以上変わらない場合は、ページを再読み込みしてください。
  • 依頼を確認するだけなら、リストチェックを直接開く URL をブックマークしておくと便利です。
スマートフォンでも使えますか？

使えます。スマートフォンのブラウザ（Chrome・Safari など）で開いてください。インストールは不要です。

ブラウザのメニューから「ホーム画面に追加」をしておくと、アプリのようにすぐ開けます。

依頼を受け取る・完了する

自分宛ての依頼はどこで確認できますか？

ホーム画面の リストチェック を開きます。横の数字は未完了の件数です。

依頼が届くと通知メールも届き、メール内のリンクから同じ画面を開けます。

未実施対応が必要な依頼の一覧です。
実施済み完了した依頼の一覧です。ここから完了の取り消しもできます。
すべて／社員依頼／店舗依頼／TFチーム依頼依頼の種類で絞り込めます。
完了報告のしかたを教えてください（社員依頼・TFチーム依頼）
  1. リストチェック の 未実施 で、対応した依頼を探します。
  2. 依頼の右側（スマートフォンでは下側）にある ✓ ボタンを押します。
  3. 「完了しますか？」と表示されたら 完了する を押します。

完了した依頼は 実施済み に移ります。社員依頼・TFチーム依頼は、宛先の一人ひとりがそれぞれ完了します（同じチームの誰かが完了しても、自分の分は完了になりません）。

店舗依頼の完了方法はこちら。

店舗依頼はどうやって完了しますか？

店舗依頼では、依頼の中に自分の管轄店舗が一覧で表示され、店舗ごとに完了します。

  1. 店舗ごとに完了する場合：店舗名の右のチェックボックスにチェックを入れます。
  2. まとめて完了する場合：依頼の右側の 全て完了にする を押し、表示された店舗を確認して 完了する を押します。
  • 1つの店舗は、担当者の誰か1人が完了すれば完了です。同じ店舗を担当する他の方にも「完了・名前（日時）」と表示されるので、重ねて報告する必要はありません。
  • 自分の管轄店舗がすべて完了すると、その依頼は 実施済み に移ります。
間違えて完了してしまいました。取り消せますか？

取り消せます。

社員依頼・TFチーム依頼実施済み で依頼を探し、完了を取り消す を押します。
店舗依頼該当の店舗のチェックを外し、確認で OK を押します。

取り消せるのは自分が付けた完了だけです。他の方が完了した店舗は取り消せないので、その方に取り消しを依頼してください。

店舗ごとに依頼を絞り込めますか？

リストチェック で 店舗依頼 を選ぶと、管轄店舗の名前が並びます。店舗名を押すと、その店舗の依頼だけが表示されます（複数選択可）。全店 で元に戻ります。

グレーの店舗名は、該当する依頼がない店舗です。

過去に完了した依頼を探したいです

リストチェック の 実施済み を開くと、上にキーワード検索が表示されます。依頼内容の言葉で検索できます。新しい依頼ほど上に表示されます。

依頼の画面の見方を教えてください
上部のラベル依頼の種類（社員依頼・店舗依頼・TFチーム依頼）、宛先、「from 依頼者名」が表示されます。
提出期限期限日です。期限が近いと 残り2日 明日まで 今日まで、過ぎると ⚠ 超過 と表示されます。
リンク・添付リンクを開く PDFを開く ZIPを開く などから資料を確認できます。
リストチェックだけをすぐ開けますか？

次の URL をブラウザのブックマークに登録してください。ホーム画面を通らず、リストチェックが直接開きます。依頼を出さない方におすすめです。

（読み込み中）

届いているはずの依頼がリストチェックに表示されません

依頼の種類ごとに、宛先の決まり方が違います。

社員依頼依頼者が選んだ役職の方に、配信した時点で届きます。配信後に役職を変えても、過去の依頼は届きません。
TFチーム依頼依頼者が選んだチームの方に、配信した時点で届きます。
店舗依頼依頼の対象店舗のうち、自分の管轄店舗について表示されます。管轄店舗に入っていない店舗の依頼は表示されません。
  1. 画面右上の丸いアイコンを押し、役職・所属チーム・管轄店舗が正しいか確認します（確認方法）。違っていれば登録内容を変更します。
  2. 登録内容が正しい場合は、依頼者に宛先に入っているか確認してください。宛先から外れていた場合は、依頼者が修正で宛先に追加できます。

依頼を出す

依頼の出し方を教えてください
  1. ホーム画面の 新規投稿 を押します。
  2. 依頼の種類を選びます（違いはこちら）。
  3. 1. 依頼内容、2. 期限（DL）を入力します。必要なら 3. URL（最大3つ）、4. 参考画像・PDF・ZIP を追加します。
  4. 5. 配信先を選びます（社員依頼は役職、店舗依頼はエリア・店舗、TFチーム依頼はチーム）。
  5. 6. 配信先の最終確認に宛先の一覧が出ます。外したい人がいればタップして外します。
  6. この内容で配信する を押します。

配信すると、宛先の方に通知メールが届き、リストチェックに依頼が表示されます。

「社員への依頼」「店舗への依頼」「TFチームの依頼」の違いは？
配信先の選び方誰が完了する？向いている依頼
社員への依頼役職宛先の一人ひとり本人の回答・入力（アンケート、個人実績の入力など）
店舗への依頼エリア・店舗店舗ごと（担当者の誰か1人）店舗での作業（POP掲示、店舗数値の入力など）
TFチームの依頼所属チーム宛先の一人ひとり特定のTFチームのメンバーだけへの依頼

迷ったら「店舗で作業が必要か？」で考えます。店舗単位の作業なら店舗への依頼、本人に答えてほしいなら社員への依頼です。

特定の人を宛先から外したい（または特定の人だけに送りたい）

6. 配信先の最終確認で、名前をタップすると宛先から外れます（もう一度タップで戻ります）。

  • すべて外す を押してから、送りたい人だけをタップすると、特定の人だけに送れます。
  • 人数が多いときは、名前・メール・役職で検索できます。
  • 右上の数字（例：12/15）は「宛先に含める人数／条件に一致した人数」です。
添付できるファイルと上限を教えてください
画像・PDF・ZIP合計3ファイルまで。PDF・ZIP は1ファイル25MBまでです。
画像が4枚以上ZIP にまとめて添付してください（例：画像2枚＋ZIP 1個）。
URL最大3つまで入力できます。

添付ファイルは自動で Google ドライブに保存され、宛先の方は依頼の画面から開けます。

期限はどう決めればよいですか？
  • 期限は今日以降の日付から選べます。
  • 期限の2日前・前日・当日の朝8時に、未完了の方へ自動リマインドが届きます。余裕のある期限にすると、自動リマインドが働きやすくなります。
  • 内容を直せるのは期限当日までです。期限を過ぎた依頼は再投稿で送り直します。

修正・再投稿・リマインド

「修正」「再投稿」「リマインド」はどう使い分けますか？
使うとき宛先入口
修正期限内に、内容・宛先・期限を直したい同じ依頼を上書き（訂正メールが届く）ホーム ▸ 修正・再投稿（上段）
再投稿期限を過ぎた依頼を、もう一度同じ宛先に送りたい前回と同じ宛先（新しい依頼）ホーム ▸ 修正・再投稿（下段）
リマインド期限を過ぎた依頼を、まだの人だけに催促したい未実施の人だけ（新しい依頼）ホーム ▸ リマインド
送った依頼の内容を直したい（期限内）
  1. ホーム画面の 修正・再投稿 を押します。
  2. 上段の 修正（期限内） から依頼を選び、この内容を修正する を押します。
  3. 内容・期限・宛先・添付を直し、この内容で訂正する を押します。
  • 同じ依頼が上書きされ、宛先の方に訂正メールが届きます。
  • すでに完了した方の記録はそのまま残ります。
  • 修正できるのは期限当日までです。
期限が過ぎた依頼を、もう一度送りたい
  1. ホーム画面の 修正・再投稿 を押します。
  2. 下段の 再投稿（期限超過） から依頼を選び、この内容で再投稿 を押します。
  3. 2. 期限（DL）を選び直し（文面・添付も変更できます）、この内容で配信する を押します。

再投稿は新しい依頼として、前回と同じ宛先全員に届きます。まだの人だけに送りたい場合はリマインドを使ってください。

まだ完了していない人だけに催促したい
  1. ホーム画面の リマインド を押します。
  2. 依頼を選び、この内容でリマインド を押します。未実施の人だけが宛先に入った状態で投稿画面が開きます。
  3. 2. 期限（DL）を選び直し、この内容で配信する を押します。
  • リマインドは新しい依頼として、未実施の人にだけ届きます。
  • 一覧に出るのは期限が過ぎた依頼です。期限前の依頼は、期限の2日前・前日・当日に自動リマインドが届くので、手動での催促は不要です。
自分が出した依頼で、誰が未完了か確認したい
  • 期限を過ぎた依頼：ホーム画面の リマインド で依頼を選ぶと、6. 配信先の最終確認に未実施の人が表示されます。配信ボタンを押さなければ何も送られないので、確認だけでも使えます。
  • TFチームの依頼：TFチーム進捗管理ダッシュボードで、依頼ごとに誰が完了したかを確認できます。

メール・通知

どんなメールが届きますか？

To Do List から届くメールの件名には、すべて「To-Do List」が入っています。差出人は r-kusaka@okamoto-group.co.jp です（システムからの自動送信です）。

依頼の内容が修正された【To-Do List】【訂正】依頼内容を修正してお送りします
期限の2日前（未完了の場合）【To-Do List】期限まであと2日です

メール内のリンクを押すと、To Do List のリストチェックが開きます。

自動リマインドとは何ですか？

期限が近づいた依頼を、まだ完了していない方にお知らせするメールです。

届くタイミング期限の2日前・前日・当日の、それぞれ朝8時ごろ
届く人社員依頼・TFチーム依頼：未完了の本人
店舗依頼：未完了の店舗を管轄店舗に持っている方
止めるには依頼を完了すれば、以降は届きません。
Gmail で To Do List のメールに自動でラベルを付けたい

Gmail のフィルタを1回設定すると、To Do List のメールすべてに自動で「To-Do List」ラベルが付きます。

  1. パソコンで Gmail を開き、上の検索ボックスに次を入力して検索します。
    subject:"To-Do List"
    To Do List のメールが一覧に出ることを確認します。
  2. 検索ボックスの右端にある 検索オプションを表示（つまみのアイコン）を押します。
  3. 右下の フィルタを作成 を押します。
  4. ラベルを付ける にチェックを入れ、ラベルを選びます。まだない場合は 新しいラベル で「To-Do List」を作ります。
  5. 過去のメールにも付けたい場合は、一致するスレッドにもフィルタを適用する にもチェックを入れます。
  6. フィルタを作成 を押して完了です。

左のメニューの「To-Do List」ラベルを押すと、To Do List のメールだけを一覧で見られます。

受信トレイをスキップ（アーカイブする） にはチェックを入れないでください。期限のお知らせを見落とす原因になります。

通知メールが届きません
  1. 迷惑メールフォルダや、Gmail のフィルタで別のフォルダに振り分けられていないか確認します。検索ボックスで subject:"To-Do List" と検索すると見つけやすいです。
  2. メールが届かなくても、宛先に入っていればリストチェックには表示されます。
  3. リストチェックにも表示されない場合は、こちらを確認してください。
依頼内容を店舗のメールアドレスに共有したい
  1. リストチェック で依頼の 店舗アドレスへ共有 を押します。
  2. 送り先の店舗にチェックを入れ（すべて選択 も可）、送信する を押します。
  • 店舗には件名「【To-Do List】期限までにご対応ください」で、依頼内容・期限・資料のリンクが届きます。店舗からの返信は、共有したあなたに届きます。
  • 共有できるのは、自分の管轄店舗のうち、店舗メールが登録されている店舗だけです。
  • 共有しただけでは完了になりません。店舗で対応が終わったら、リストチェックで完了を押してください。

担当・登録内容の変更

管轄店舗・役職・チームなど、登録内容を変えたい

異動で担当が変わったときや、管轄店舗を増やしたい・減らしたいときは、ご自身で変更できます。

  1. 画面右上の丸いアイコン（自分のイニシャル）を押し、一番下の ログアウト を押します。
  2. ログイン画面でご自身の社内メールアドレスを入力し、ログイン情報を変更 を押します。
  3. 役職・チーム・エリア・テリトリー・管轄店舗を直し、変更を保存 を押します。
  4. 内容を確認してログインします。
  • 変更後は、新しい管轄店舗の依頼（まだ完了していないもの）も表示されるようになります。
  • これまでの完了記録は消えません。
自分の登録内容（管轄店舗など）を確認したい

画面右上の丸いアイコン（自分のイニシャル）を押すと、役職・担当エリア・テリトリー・管轄店舗・所属チームが表示されます。

管轄店舗の選択肢に、担当の店舗が見つかりません
  • まず、その店舗のエリアとテリトリーを選んでいるか確認してください。選んだテリトリーの店舗だけが表示されます。
  • 新しくできた店舗などで選択肢に出ない場合は、DXチームに店舗名とエリア・テリトリーをご連絡ください。店舗を追加します。
画面の色は変えられますか？

画面右上の丸いアイコンを押し、アクセントカラーから好きな色を選べます。変わるのは自分の画面だけです。

TFチーム進捗

TFチーム進捗管理ダッシュボードはどこから開きますか？

画面右上の丸いアイコンを押し、TFチーム進捗の 〇〇チーム進捗管理ダッシュボード を押します。複数のチームに所属している方は、チームごとに表示されます。

「所属チーム未設定のため開けません」と表示される場合は、登録内容の変更でチームを設定してください。

ダッシュボードでは何が確認できますか？
  • 自分のチーム宛ての TFチーム依頼について、依頼ごとの進捗率・期限・誰が完了したかを確認できます。
  • すべて 未完了のみ 期限超過のみ で絞り込めます。
  • ダッシュボードは見るための画面です。自分の完了報告はリストチェックで行います。
